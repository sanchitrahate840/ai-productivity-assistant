# AI Productivity Assistant

An AI-powered personal productivity platform for managing tasks, notes, schedules, reminders, and productivity analytics.

## Tech Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: PostgreSQL
- AI Service: Python + FastAPI
- Authentication: JWT + bcrypt
- Real-time: Socket.IO
- AI: LLM API + LangChain
- Semantic Search: pgvector
